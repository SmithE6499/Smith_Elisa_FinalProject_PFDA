## Description
I am planning to create a simple pong-like game using turtle module. This is relavent to media and 
digital arts because it is a combination of both visuals and coding.

## Features
- Feature 1
	- An interactable/playable bar to hit the ball will be porgrammed to take keyboard input and move on the screen.
- Feature 2
	- a local two player feature will be made by having two player bars that respond to different areas of the keyboard (WASD or Directional Arrows)
- Feature N 
	- There will be a scoreboard that will keep track of each player's points, updating at the end of each game and also resetting to a new game.

## Outcomes
Ideal Outcome:
- Ideally my game should be functioning and be able to take the input given. Two people should be able to play locally 
with any keyboard available. The game should play at a decent/engaging speed that isn't too fast or slow. 

Minimal Viable Outcome:
- Bare minimum would be two bars that move and the ball interactrs with them correctly. If the game plays a 
little slower, that is fine too. The counter should also work no matter what.
